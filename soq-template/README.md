# CSI SOQ template (simple)

A plain, modern Statement of Qualifications layout for CSI Engineering. It is the reference the SOQ
app copies. Open `index.html` in a browser, or print it to PDF (US Letter, no margins, background
graphics on). `preview/` holds a rendered PDF and one PNG per page.

## Pages

1. Cover: full-width field photo, CSI Blue bar, navy panel with the white logo, title and RFQ facts
2. Cover letter
3. Contents
4. Firm overview: photo band, main text, facts rail
5. Section divider (navy)
6. Project sheet: photo band, challenge / what CSI did / result, facts rail
7. Résumé: headshot (or initials tile), projects, credentials rail
8. Approach: phase table and two supporting points
9. Back cover (navy, logo, point of contact)

## Rules

- Every corner is square (`border-radius: 0` everywhere). No gradients, shadows, angled cuts or
  decorative shapes.
- Colours: Navy `#14275A`, CSI Blue `#254593`, Ink `#0E1117`, Grey `#5B6472`, Mist `#F3F5F9`, rules `#D5DAE3`.
- Type: Red Hat Display (titles, 300/400) and Red Hat Text (body 13.33 px on 20 px). At most four sizes a page.
- Page: 816 x 1056 px, 64 px side margins, main column plus a 224 px rail.
- Logo: the real files in `img/` only, never redrawn. Blue on white pages, white on navy.
- Photos: real CSI field photos only. Everything in [brackets] is filled from the Knowledge Hub;
  nothing is invented.
