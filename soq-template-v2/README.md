# CSI SOQ template v2

Built from the won-SOQ research in soq-v2 (`research/goat-2026-11`: 153 measured pages, evaluator scoring study).
Open `index.html`, or see `preview/`. 11 pages: cover, letter, response map, firm, divider, project sheet,
résumé, org chart with hours table, approach, QA/QC, back cover.

What the research changed from v1:
- Denser pages (body 13.5/20 px, main column + 210 px rail) so pages carry the word counts winners carry.
- Bold interior headings that state a benefit, the RFQ item number above, and one theme sentence under each.
- A response map that ties each RFQ criterion to its page.
- One dominant visual per page (photo, chart, process strip, loop, org chart) with an action caption.
- One proof callout per page (navy block) holding a number, a name or a quote.
- Availability in hours a month, not percentages.
- Square corners, navy + CSI Blue + one light accent, Red Hat Display/Text. Everything in [brackets] comes from the Hub.
